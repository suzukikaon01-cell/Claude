# 裂境战场 · 3D MOBA 人机对战

可在浏览器本地运行的 5v5 人机对战原型。包含原创法师「零」、盖伦、艾希、拉克丝、亚索、易大师、卡兹克、瑟提，九种召唤师技能和30件成装，原创低多边形 3D 英雄与武器、三路与野区、草丛、空营地、18 座防御塔、塔皮与金币分配。

## 开始

解压后直接打开 `dist/index.html`。全部资源随包提供，无需联网。推荐平板横屏或桌面浏览器，支持 WebGL 2。

也可安装 Node.js 后运行 `node serve.cjs`，打开 http://127.0.0.1:4173 。

左摇杆移动，右侧普攻及技能。开局先按技能旁的 `+` 学习 1 个技能。技能可拖动瞄准，松手施放，拖到取消区取消。方向键也可移动，Q/W/E/R 施法，1–4 升级，B 回城，D/F 召唤师技能，P 商店，Esc 暂停。

自动攻击默认关闭：点按普攻一次，按住普攻键连续攻击，松开停止。所有玩家与人机英雄的实际移动速度统一乘以 0.65（较上一版降低 35%）；英雄详情显示应用倍率后的移速。

最新验收和数值以 `UPDATE-V6.md` 为准，完整装备表见 `ITEM-REPORT-V6.md`；旧报告作为历史记录。地图15000×15000，默认18级兼容模式。零进化阈值25/65/95/125，最新普攻393.75、Q450、W525、R562.5。技能长按不滑动查看说明，滑动瞄准、松手释放。

## 源码与数值

- `dist/config.js`：英雄基础、成长、技能、装备与移动速度系数。
- `dist/terrain.js`：共享地面纹理绘制。
- `dist/world.js`：地图大小、墙体、草丛、营地、防御塔和奖励池。
- `dist/rules.js`：统一成长、攻速、抗性与伤害数学。
- `dist/champion-mechanics.js`：技能、状态、治疗、护盾、弹道与四英雄机制。
- `dist/game.js`：输入、原战斗循环、AI、寻路与经济。
- `src/renderer.js`：原创建模与 3D 动画，使用 Three.js。
- `dist/renderer.js`：已打包的渲染器，可以离线运行。
- `CHANGELOG-v4.md`：本版关键公式、数值变化与测试说明。
- `CHANGELOG-v3.md`：早期原型历史，数值已由 V3 英雄规格替代。

需要修改 3D 模型时，先 `npm install`，再编辑 `src/renderer.js`，运行 `npm run build`。修改其余 `dist/` 文件无需构建，刷新浏览器即可。

运行 `npm test` 或 `node test.cjs` 执行回归测试。

本项目是玩法原型，未复用官方美术与模型。已有草丛隐藏，但没有全地图战争迷雾、龙/男爵、联网匹配和完整野区生态。真实平板多点触控与不同移动 GPU 的帧率需真机测试。

所有英雄普通攻击距离再降低 50%：艾希 300、盖伦 87.5、拉克丝 275、零 262.5。玩家与人机共用；盖伦 Q 仍额外增加 25 攻击距离，ZERO V5 最新覆盖为普攻 525、Q 600、W 700/半径260、R 半径750。

当前为 4 英雄版本：艾希、盖伦、光辉、零。新英雄行为可通过 `registerBehavior` 注册；`dist/combat-core.js` 提供固定时钟、状态、事件、空间索引、输入缓冲和位移服务。`dist/zero-growth.js` 管理零的永久成长与进化；`dist/match-checkpoint.js` 保存完整对局对象图。刷新后可在大厅选择“继续上次对局”，新开一局会重新开始。

运行 `node test.cjs` 执行全部功能回归；运行 `node --expose-gc test-stress.cjs` 执行逻辑压力测试并生成 `engine-benchmark.json`。浏览器画布的 `data-diagnostics` 包含只读性能快照。
