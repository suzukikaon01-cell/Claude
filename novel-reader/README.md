# 纸页 · 小说阅读器（PWA）

纯前端、离线可用的小说阅读器，数据全部保存在本机（IndexedDB）。

- **进入需验证**：首次设置密码（PBKDF2 加盐哈希存储，5 次错误锁定 30 秒）；可在设置里开启**扫脸解锁**（调用设备 Face ID / 人脸识别，基于 WebAuthn 平台认证器）。切到后台自动锁定。
- **纸质翻页**：纸张纹理 + 3D 卷页动画，可手指拖动跟随翻页；点左/右侧翻页，点中间呼出菜单（进度条、字号）。
- **书架**：导入 `.txt`（自动识别 UTF-8 / GBK），自动识别章节标题，记住阅读进度。
- **图集 / 视频集**：导入本地图片、视频，网格浏览，全屏查看、左右滑动切换、播放。

## 运行
```bash
cd novel-reader && python3 -m http.server 8080
```
手机访问需 HTTPS（扫脸功能要求），部署到任意静态托管（GitHub Pages / Cloudflare Pages）后，在 Safari/Chrome 中“添加到主屏幕”即可像 APP 一样使用。
