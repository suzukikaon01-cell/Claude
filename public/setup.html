一键安装推荐

点按钮会先复制地址，再打开安装。安装时 iPhone 会问“粘贴记账地址”，长按粘贴即可。

  1. 安装后：快捷指令 →「自动化」→「＋」→「電子ウォレット」→ 全选卡片 →「すぐに実行」→ 下一步 → 在「マイショートカット」里选「ApplePay自动记账」
  2. 截图记账：设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选「截图记账」

① Apple Pay（Suica・信用卡）全自动约 1 分钟

打开快捷指令 App
  1. 下方「自动化」→ 右上「＋」→「电子钱包」→ 勾选 Suica 和所有卡 → 选「立即运行」→ 下一步 →「新建空白自动化」
  2. 添加动作「文本」，粘贴文字模板，然后把 商家、金额、卡片 三个词各点一下，换成同名的蓝色变量（快捷指令输入 → 商家／金额／卡片或票卡）
  3. 添加动作「获取 URL 内容」→ 粘贴地址 → 展开：方法 POST，请求体 文件，文件选上面的「文本」→ 完成

② PayPay・实体卡：截图记账约 1 分钟

  1. 「快捷指令」标签 → 右上「＋」→ 依次添加：「截屏」→「从图像中提取文本」→「获取 URL 内容」（粘贴地址，方法 POST，请求体 文件 = 提取的文本）
  2. 命名为「截图记账」
  3. 设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选「截图记账」

之后在支付完成页／收据／明细列表敲两下手机背面即可。
